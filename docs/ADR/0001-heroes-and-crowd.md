# ADR 0001 — Heroes vs crowd

- **4 heroes** run the frozen LIF graph (toy in v0; compact MaleCNS later).
- **Crowd** (default 64) carry the same adapter genome and cheap sensors. No spikes.

Heroes exist to be inspected. Crowd exists so wear can make a city on a laptop.
Both share one agent interface (`flyciv.colony.agent`).
